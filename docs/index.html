Installation & Prerequisites Guide

Step-by-step installation instructions for every operating system and workflow.

1

Open Visual Studio Code

BetterGitGraph requires VS Code 1.90.0 or newer.

2

Quick Open Install

Press Cmd+P (macOS) or Ctrl+P (Windows/Linux) and paste:

ext install Renoceros.bettergitgraph
3

Open Your Graph

Press Cmd+Ctrl+G (macOS) or Ctrl+Alt+G (Windows/Linux), or click the BetterGitGraph icon in the top right editor tab.

1

Install Git CLI

BetterGitGraph interfaces with your local Git binary directly so all your SSH keys and GPG signatures are preserved:

# macOS (Homebrew)
brew install git
# Windows (Winget)
winget install --id Git.Git -e --source winget
# Linux (Debian / Ubuntu)
sudo apt update && sudo apt install git
2

Configure Git Identity

Set your global commit author name and email:

git config --global user.name "Your Name"
git config --global user.email "you@example.com"
1

Download VSIX

Grab bettergitgraph-1.3.2.vsix from our GitHub Releases Page.

2

Install via CLI

code --install-extension bettergitgraph-1.3.2.vsix

Frequently Asked Questions & Troubleshooting

Everything you need to know about compatibility, security, and Git operations.

[?]
What do I need to install before using BetterGitGraph? ▼

You only need VS Code (version 1.90.0 or newer) and the Git CLI installed on your machine. BetterGitGraph executes native Git commands locally through simple-git, preserving all your SSH keys and GPG signing identities.

Do I need the GitHub CLI (gh) to create Pull Requests? ▼

No! BetterGitGraph parses your origin remote URL (GitHub, GitLab, Bitbucket, Azure DevOps) and generates direct web comparison URLs. Clicking "Raise PR / Create MR" opens your browser directly with base and head branches pre-filled.

How does the Commit & Staging Studio work? ▼

Whenever uncommitted changes exist, an emerald dashed WIP node ($\bigodot$) is attached to HEAD. Clicking it opens the Commit Drawer to stage/unstage files, click diff links, use Conventional Commit chips (feat:, fix:), and commit or amend.

What is the Two-Stage Confirmation guardrail? ▼

Destructive actions like Hard Reset, Force Push, and Force Delete Branch enforce a 2-stage verification modal with a red warning banner. You can toggle this in settings: bettergitgraph.twoStageConfirmation (default: true).

Why is the main branch thicker? Can I customize curve thicknesses? ▼

The central trunk defaults to 7px and feature branches to 3px to visually anchor the tree. Both are fully configurable in VS Code settings via bettergitgraph.mainTrunkStrokeWidth and bettergitgraph.branchStrokeWidth.

Does BetterGitGraph collect telemetry or send code to remote servers? ▼

Zero telemetry. BetterGitGraph is 100% local-first and operates under a locked-down Content Security Policy with zero external network requests.
