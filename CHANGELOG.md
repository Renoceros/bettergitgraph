# Changelog

All notable changes to BetterGitGraph will be documented here.

## [Unreleased]

### Added
- Initial project scaffold
- Extension manifest with commands, keybindings, tree view, and settings
- `GitDataLayer` — typed interface to git via simple-git
- `BranchExplorerProvider` — recursive remote ref file tree in sidebar
- `BranchColorEngine` — deterministic FNV-1a branch colors
- `WebviewManager` — webview panel with postMessage bridge
- CI pipeline (GitHub Actions)
- Documentation: PRD and Technical Docs
- Agent context protocol (`.agent/` directory)
